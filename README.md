**📧 Nano-Boom 🔥
Email Stress Testing Tool**

**📌 Overview**
Email Bulk is an email stress-testing tool designed for educational and authorized testing purposes.
It allows you to send multiple test emails using randomized content, dynamic subjects, and multi-threaded processing to evaluate email system performance under controlled workloads.

**⚠️ IMPORTANT**
This tool is intended only for testing your own email accounts and systems or environments where you have explicit authorization.
Unauthorized use is strictly prohibited and may be illegal.

**🛠️ Installation**
**📱 Termux (Android)**

rm -rf ~/nano-boom

pkg update -y

pkg install python git -y

git clone https://github.com/ExploitXpertt/nano-boom.git

cd nano-boom

pip install colorama

python3 Boom.py
